### unknowns
(1) Whether the HF repo was publicly visible between its June-2023 creation and the 2025 README/GitHub-link updates cannot be determined from the HF API (no visibility history); the June-2023 data commits are verified, discoverability is not. (2) Why XBRLTagRec's re-run of FLAN-FinXC scores Macro-F1 0.4616 vs the original 66.23 on what is the same test set is unexplained in the paper; whether they score the 770 'Others' rows is unknown. (3) What the 'Others' rows in the FLAN-FinXC-Data consolidated CSVs represent (negatives / non-US-GAAP numerals) is undocumented. (4) The exact mechanism of the 'self declaration ... solely for research purposes' is not specified anywhere; no LICENSE file exists on HF or GitHub, so derived-data redistribution rights remain legally unclear and should be confirmed with the authors. (5) The WebSearch budget was exhausted before this task started and Semantic Scholar rate-limited two of three queries, so no Google-Scholar-style discovery of further papers using FNXL was possible; all evidence comes from direct fetches of HF, GitHub, Google Drive, arXiv and the datasets-server/S2/arXiv APIs.

### notes
RESOLUTION: The HF release (soummyaah-space/FNXL) is the FULL dataset. data/fnxl/finer/{train,dev,test}.csv = 62,782 / 6,823 / 9,483 sentence rows and data/fnxl/xml/{train,dev,test}XmcDf.csv = 111,493 / 13,191 / 18,238 numeral rows with 2,692 / 1,273 / 1,374 labels and 798 / 756 / 794 companies, an exact cell-for-cell match to Table 1. The HF viewer's 1.3M/158K/219K 'rows' are a parquet-conversion artifact (single 'text' column of .txt lines). The 'partial' Drive data used by XBRLTagRec (FLAN-FinXC-Data/Data.zip) is in fact the full train (111,493 tagged + 16,745 'Others') and full test (18,238 tagged + 770 'Others') with the dev split omitted; its tagged test sentences are exactly the 9,483 HF test sentences. The second Drive folder linked by FLAN-FinXC's README holds byte-identical copies of the HF CSVs. FLAN-FinXC never claims a partial release; only XBRLTagRec does, and the claim is wrong. CONSEQUENCE FOR THE PROJECT: FNXL can serve as a secondary benchmark with numbers directly comparable to FLAN-FinXC's 66.23 Macro-F1 / 89.98 Hits@1 (full test set, 18,238 numerals) using HF xml/testXmcDf.csv; XBRLTagRec's 0.5050 is on the same test set but under an unexplained evaluation discrepancy, so cite it with that caveat. LICENSE: research-only per the HF sub-card, no formal license file; derived training data should not be redistributed without author permission.
