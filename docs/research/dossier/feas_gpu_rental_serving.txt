### unknowns
1) Vast.ai prices could only be confirmed via the GetDeploying aggregator (dated 2026-10-01); vast.ai's own per-GPU pages are JS-rendered and showed 'No current offers'. 2) RunPod serverless Flex vs Active per-second rates were not shown on the pricing page as fetched; only per-hour tier prices. 3) Modal lists 'A10' and its docs never say 'A10G'. 4) No published, reproducible serving benchmark (TTFT/TPOT percentiles, req/s) was found for a text-only 1-3B model on an NVIDIA L4 or A10G specifically; nearest verified anchors are Qwen2.5-3B on RTX A5000 (24GB Ampere) and RTX 4090, Gemma-3-4B on A100-40GB (DatabaseMart, Aug 2026), starcoder2-3b on L4 (504.8 tok/s, vLLM issue), and the Qwen2.5-7B L4/A100/H100 Pareto Atlas paper. 5) Semantic Scholar API returned HTTP 429 on all three attempts; arXiv API searches were used instead. 6) Groq's pricing page did not expose per-token prices to the fetcher. 7) Together's pricing page no longer shows a parameter-size tier table and neither Together nor Fireworks offer Llama 3.2 3B serverless; the only verified sub-4B serverless rates are Fireworks' generic '<4B = $0.10/M tokens' tier and DeepInfra's Gemma 3 4B ($0.05/$0.10). 8) vLLM's compatibility matrix on the docs site 404'd at every URL tried; the GitHub docs/features/README.md copy was used and it contains no quantization row, so LoRA-on-AWQ/GPTQ/FP8 compatibility is only inferred from the 2024 QLoRA PR and not from a current matrix. 9) WebSearch budget was exhausted before this task began, so discovery relied solely on direct fetches of known URLs and arXiv/GitHub APIs; relevant blog posts with L4/A10G 3B numbers may exist but were not discoverable here.
