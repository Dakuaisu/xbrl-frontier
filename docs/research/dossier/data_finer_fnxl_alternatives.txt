### unknowns
1) FNXL dataset license is contradictory/unclear: GitHub license null, HF repo untagged, inner data README says 'Research-only use' (the arXiv paper itself is CC BY 4.0) - treat as research-only unless authors confirm. 2) FinTagging training-split sizes were not visible on HF/GitHub pages (README references TrainingSet_Annotation.json; HF cards show only 'test' splits of 6,599 rows for v1 and 46,496 for v2). 3) Company-level overlap between FinTagging (2023-24 10-Ks) and FiNER-139/FNXL filers was not determinable from public pages. 4) FinNI-eval / FinCL-eval / FinTagging_BIO license tags are not shown on their HF cards (FinTagging_Original is MIT). 5) Semantic Scholar API returned HTTP 429 on every attempt; citation counts come from OpenAlex instead. 6) NORA's 6.6M-instance benchmark has no public release link in the paper HTML. 7) edgartools/ixbrl-parse/py-xbrl READMEs do not state whether parsed iXBRL facts retain HTML element/character positions; building span-labelled training data from iXBRL will likely require custom parsing of ix:nonFraction elements. 8) WebSearch budget was exhausted at session start, so discovery relied on direct fetches of arXiv export API, HF API listings, OpenAlex, GitHub API and SEC pages; coverage of non-arXiv venues is incomplete.

### notes
Key takeaways for the project: (a) FiNER-139 (text-only, 2016-20, 139 tags, CC-BY-SA-4.0) and FNXL (text-only, 10-K 2019-21, 2,794 tags, research-only per README) are both sentence/token-level and exclude tables, whereas FinTagging (10-K 2023-24, iXBRL-derived, text+tables, ~17.7k-concept taxonomy, MIT on FinTagging_Original) is the only one covering tables; filing years do not overlap FinTagging, so training on FiNER/FNXL and evaluating on FinTagging has no temporal leakage. (b) Since all 10-K/10-Q have been iXBRL since mid-2021, auto-labelled training data can be generated at scale from SEC public-domain filings (monthly XBRL RSS index + companyfacts/frames APIs + Arelle or custom ix:nonFraction parsing) under the 10 req/s + User-Agent policy; no existing public corpus already provides iXBRL facts with character spans. (c) Among prior XBRL-tagging papers fetched (FiNER, FNXL, FLAN-FinXC, XBRLTagRec, FinTagging, NORA), none reports serving latency or cost; the closest precedent is FinLoRA, which reports fine-tuning and inference time/GPU memory for LoRA'd LLMs on its own XBRL-analysis tasks (not FinTagging/FNXL/FiNER).
