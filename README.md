# xbrl-frontier

An accuracy / cost-per-filing / latency frontier for fine-tuned Qwen3-0.6B and Qwen3-1.7B students on FinTagging FinNI, measured against pinned frontier APIs on identical instances, with fp16 / INT8 / INT4 serving on a market-priced T4 and on owned hardware. The deliverable is the harness and the chart, not a model. Spec: `docs/PRD.md`; decisions: `docs/TRADEOFFS.md`; findings: `docs/OPEN.md`.

## Contamination statement (draft, generated by scripts/contamination_statement.py)

**Evaluation set.** FinTagging FinNI-eval-v2 at revision `e3e0aba23b5c3df17a71c8c013030182d013a538` (28,787 rows). Its filings were recovered from EDGAR: 129 of 142 registrants (`contamination.eval_manifest_required_recovered` NOT MET; O-010), 139 filings dated 2024-02-06 to 2025-02-13. Instances mapped to a filing: 95.25% raw / 95.39% dedup with the benchmark's own serializer (Phase 0 token matcher: 94.29% / 94.43%); the unassigned stratum is excluded from the frontier sample.

**Training data exclusion.** Training filings are 10-K/10-Q filed 2021-02-13 to 2023-02-12 (strictly before the eval window), from CIKs outside data/eval_manifest.csv, research/edgar_submissions_train10.json, data/eval_cik_candidates_unconfirmed.txt (151 CIKs excluded; the last file lists the 15 FTS-resolved but unconfirmed CIKs, excluded conservatively, T-008). One filing per company.

**Overlap audit.** Every training instance eligible for the corpus (215,284) was checked against every eval context (25,765 distinct) with 13-gram overlap (lm-eval-harness style) and MinHash (128 permutations, Jaccard >= 0.8). Flagged: 18,184 (8.4%; 2,801 positives, 15,383 negatives; 12,867 by n-gram only, 5,317 by both, 0 by MinHash only), all removed. Re-audit of the final corpus: 0 flagged of 40,721.

**Corpus size.** Train 38,788 instances (cap 40,000 not reached after decontamination, O-016); dev 1,933 (cap 2,000 not reached after decontamination, O-016).

**What decontamination removed (O-017).** Training positives before the audit: table share 0.516, median 273 tokens; after: 0.480, median 236 (eval: 0.530, 293). Long tables share more 13-grams with eval boilerplate, so the corpus is somewhat shorter and less table-heavy than the eval; this is reported next to the table slice.

**Model cutoffs vs eval dates.** Frontier arms: `gpt-6-luna` 2026-05-18; `gpt-5.4-mini-2026-03-17` 2025-08-31; `gemini-3.5-flash-lite` 2026-03 (vendor docs).
